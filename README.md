Simple Portfolio Website

About the Project

This is my first simple portfolio website, built using HTML and basic CSS as part of my web development learning journey. As a beginner, I created this project to apply the concepts I learned and gain hands-on experience in building a website. I used simple styling, colors, spacing, and layouts to create a clean and beginner-friendly design.

Pages

- Home Page: Introduces me, my interests, and my projects.
- Contact Page: Provides contact information and a way to connect with me.

Sections

- About Me: A brief introduction about myself and my learning journey.
- My Interests: Highlights my hobbies, such as cooking, reading, content creation, cricket, and music.
- My Projects: Showcases my project ideas and work.

Technologies Used

- HTML5
- CSS3

What I Learned

- Structuring web pages using HTML.
- Styling elements with basic CSS properties.
- Working with colors, padding, margins, and borders.
- Creating simple layouts and aligning elements.
- Organizing website content into sections.

Purpose

The purpose of this project is to strengthen my HTML and CSS fundamentals and take my first step toward becoming a Full Stack Developer.
